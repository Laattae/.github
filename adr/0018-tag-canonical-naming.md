# 0018. 태그 대표 표기는 뉴스에서 쓰는 말로 정한다

- 상태: 승인
- 날짜: 2026-11-27
- 범위: StocksTag

## 맥락

같은 대상이 여러 표기로 나뉘어 있으면 뉴스에 "애플"이 나와도 `Apple` 태그가 붙은 7종목이 연결되지 않는다. 고객사 591개 중 상장사 alias와 바로 맞는 것은 66개뿐이었고, 한·영 표기(Apple 7 · 애플 3), 옛 사명(기아자동차), 그룹명(현대기아, 현대/기아)이 섞여 있었다. 금리/이자율, 2차전지/이차전지, LNG/액화천연가스, 싱가폴/싱가포르처럼 다른 축에도 같은 문제가 있었다.

동의어로 묶으면 매칭은 어느 표기로든 되므로, 대표 표기는 사람이 읽고 뉴스와 맞추기 편한 쪽으로 정하면 된다.

## 결정

| 대상 | 대표 | 예 |
| --- | --- | --- |
| 해외·비상장 기업 | 한국 뉴스에서 쓰는 한글 표기, 영문은 동의어 | Apple → 애플, NVIDIA → 엔비디아 |
| 뉴스가 영문 약칭을 쓰는 기업 | 영문 약칭 | GSK, ZF, TSMC, GM, BMW |
| 상장사 | 종목명(`stock_name`). 종목명이 영문 음차면 영문 | 현대차 → 현대자동차, 케이티 → KT, LG씨엔에스 → LG CNS |
| 옛 사명 | 현재 사명 | 기아자동차 → 기아, 현대중공업 → HD현대중공업 |
| 그룹 | 회사와 따로 둔 그룹 태그, 계열사는 하위 관계(0020) | 현대기아·현대/기아 → 현대차그룹 |
| 품목·변수 | 금융 뉴스에서 더 쓰는 말, 업계 약어는 약어 | 이자율 → 금리, 이차전지 → 2차전지, 액화천연가스 → LNG |
| 지역 | 표준 국가명, 시도는 본사 지역 태그와 같은 약칭 | 싱가폴 → 싱가포르, 전라남도 → 전남 |

- 상장사는 `stock_alias`로 자동 매칭하고(법인 접미사 제거, 엘지·에스케이 같은 음차 변환), 해외·비상장사와 옛 사명은 사람이 쓴 사전(`customer_groups.csv`)으로 묶는다.
- 채널·자회사는 회사와 합치지 않는다(구글 플레이스토어, 아마존프라임비디오, Chevron Australia). 뜻이 갈리는 표기도 합치지 않는다(미주 ≠ 북아메리카, Merck ≠ MSD).

## 검토한 대안

- **가장 많이 쓰인 표기를 대표로**: 공시 원문 기준이라 이자율·이차전지처럼 뉴스와 다른 표기가 대표가 된다.
- **상장사도 전부 한글 음차(종목명 그대로)**: 매칭에는 문제가 없지만 KT가 `케이티`로 보여 읽기 불편하다.

## 결과

- 고객사 태그는 591개에서 519개로 줄었고, 상장사인데 표기가 여러 개인 경우는 0건이다(SK하이닉스 26, 현대자동차 22, 애플 10 …).
- 영문으로만 남은 고객사 137개는 대부분 1종목짜리 해외 거래처라 두었다. 뉴스에 한글로 자주 나오면 사전에 추가한다.
