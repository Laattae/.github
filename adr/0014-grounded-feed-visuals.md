# 0014. 피드 씬의 핵심 정보를 자료 이미지와 설명 그래픽으로 전달한다

- 상태: 제안
- 날짜: 2026-11-24
- 범위: lattae-feed

## 맥락
일반적인 배경 사진만으로는 기업명, 연도, 조직 재편 같은 대본의 핵심이 전달되지 않는다. 사용자가 자료 사진·도식·AI 이미지 선택, 로컬 생성 루프, 동일 입력 기준의 명확한 변경 추적을 요청했다.

## 결정
- Qwen3 8B에 기사와 앞뒤 대본을 함께 전달한다. 화면에 표시할 한국어 사실은 원문의 연속 인용과 근거로 검증하고, 확인되지 않는 인물·개편 내역은 비워 둔다.
- 기업·인물은 Wikimedia Commons 자료 후보를 검색하되 출처·설명·이용 조건과 대상 일치를 확인한다. 확인 실패·네트워크 장애에는 기업명과 검증된 핵심 구절을 표시한 그래픽으로 전환한다. 촬영 시점 미확인 자료를 사건 당시 사진으로 표시하지 않는다.
- 조직 재편, 전후 비교, 타임라인은 코드로 제작한다. 구체적 조직 내역을 확인하지 못한 그래프는 부서명 없는 개념도로 표시한다. 일반적 상황만 AI 이미지로 생성한다.
- 기존 사진 경로를 비교 기준으로 유지한다. 대표 씬의 비교 보고서에는 같은 대본·음성, 코드 커밋, 설정, 실행 시간, 출처·대체 이유, 프레임·영상 해시 및 사람 검수 결과를 남긴다. 사람 검수가 없으면 미검수로 기록한다.
- 워커 완료 메타데이터에 시각화 버전, 코드 커밋, 씬별 계획·출처·검사·타이밍과 출력 해시를 저장한다. ADR 0007의 기사 단위 멱등 처리와 ADR 0011의 설정 분리를 유지한다.
- 대표 입력 검증 후 grounded 경로를 명시적으로 선택하여 연속 워커를 실행한다. 기존 완료 기사는 덮어쓰지 않는다.

## 검토한 대안
- 이미지 모델만 교체: 대상·시점·추상적 변화를 전달하는 문제를 해결하지 못한다.
- 모든 씬을 생성 영상으로 교체: 사실성 검증과 처리 시간 부담이 커 초기 범위에서 제외한다.
- 검색 상위 이미지를 무조건 사용: 대상 오인과 이용 조건 누락 때문에 제외한다.

## 결과
구현 및 로컬 검증 결과는 후속 갱신한다. Commons에 적합한 자료가 없으면 설명 그래픽 비율이 높아질 수 있다. 텍스트 검증을 이미지 사실성 검증이나 사람 승인으로 간주하지 않는다.
