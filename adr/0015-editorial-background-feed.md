# 0015. 전체 배경 이미지와 기사 핵심 자막 형식으로 피드를 개선한다

- 상태: 제안
- 날짜: 2026-11-24
- 범위: lattae-feed

## 맥락
사용자가 ADR 0014의 카드·조직도 중심 결과물 품질을 거부하고 기존 전체 이미지 배경 + 자막 형식을 유지하도록 방향을 변경했다. 문맥에 맞는 최신 이미지 모델, 기사 핵심을 전달하는 대본, 명확한 전후 비교, 기존 PR #4 갱신과 로컬 연속 생성을 요청했다.

## 결정
- 전체 화면 사진 배경 + 고정 자막·TTS·기존 디졸브를 유지한다. 카드·조직도·타임라인 생성 경로는 기본 워커에서 제거한다.
- 대본·프롬프트 작성과 검토는 Gemma3 12B Q4_K_M을 사용한다. Qwen3 8B의 실제 초안에서 부자연스러운 한국어와 반복 회의실·군복 묘사가 나와 출시 판단에서 제외했다. 원문 문장 ID를 근거로 핵심 사건·수치·변화·확인된 후속을 선택한다. 같은 내용 반복과 일반적인 감상·포부로 씬을 채우지 않는다. 사실성·중요도·한국어 문장성 검토를 통과한 대본만 쓴다.
- 프롬프트는 기사 전체와 해당 대본을 함께 보고 구체적인 피사체·행동·환경·장면 관계를 묘사한다. 익명 인물과 구체적 산업 환경을 허용한다. 일반 사무실·빈 책상으로 모든 사건을 대체하지 않는다. 생성 사진을 실제 사건·실존 인물의 기록 사진으로 주장하지 않는다.
- 이미지 모델은 공식 Apache 2.0 FLUX.2 klein 4B를 우선 검증한다. BF16, CPU offload, 약 1MP 세로 해상도, 4 steps를 사용한다. 공식 13GB 안내를 근거로 16GB 장치에서 실제 실행·문맥·메모리를 확인한다. 보편적인 최고 모델이라는 단정 대신 이 장치의 채택 근거를 기록한다.
- 전후 비교는 같은 기사, 같은 참조 음성으로 기존 SDXL Turbo + 기존 대본과 새 모델 + 핵심 대본을 비교한다. 대본이 달라 WAV와 길이도 달라질 수 있음을 명시한다. 추가로 같은 프롬프트/시드의 이미지 비교로 모델 효과와 대본 효과를 구분한다.
- 원문·대본·근거·검토·영어 프롬프트·모델 revision·시드·설정·소스 해시·단계별 시간·영상 해시·실패 시도를 기록한다. 자연키 멱등(0007)과 설정 분리(0011)를 유지한다.
- 실제 생성 영상을 확인한 뒤 연속 루프를 가동하고 PR #4의 설명과 최종 diff를 새 방향에 맞춘다. 이전 실패 실험은 이력으로 보존한다.

## 검토한 대안
- 작은 자료 사진과 설명 카드: 사용자가 품질을 거부했으므로 운영 채택에서 제외한다.
- SDXL Turbo 유지: 문맥 표현과 시각 품질 개선 범위가 제한돼 최신 모델 비교 대상으로만 남긴다.

## 결과
2026-11-25 로컬 RTX 5060 Ti 16GB에서 FLUX.2 klein 4B의 768×1344 사진 생성과 VoxCPM2·FFmpeg 합성을 실행했다. 같은 기사 141·참조 음성 비교에서 기존 22.066667초와 개선 30.200000초 영상을 확인했다. 두 영상은 1080×1920 H.264·30fps·AAC다. 대본이 바뀌므로 실제 WAV는 서로 다르다. 모델만의 별도 비교는 같은 프롬프트·512×896·seed 42·4 steps로 남겼다.

완성 프레임 검토에서 손 겹침·지역 불일치·기계 조작으로 바뀐 경영 지휘·가짜 조직 발표 화면을 발견해 제외 또는 보정했다. 기사 근거에서 지역 조건을 추출하고, 같은 후보 안에서 3·4번 장면만 재생성했다. 이 보정은 같은 WAV와 나머지 3장을 재사용했으며 실제 보정 seed 42·43을 별도로 기록했다. 최초 5장 로드 56.145초, 개별 생성 합 124.349초, PyTorch 최대 GPU 할당 7.764GiB를 관측했다. 이 수치는 전체 장치 VRAM/CPU RAM이나 전체 자동 생성 시간과 다르다. 최종 합성 시간도 준비 단계와 재사용 비용을 분리한다.

PostgreSQL 포함 118개 테스트 통과(선택 MLflow 1개 제외). 사전 점검과 별도로 2026-11-25 15:19 KST 연속 워커를 시작했고 기사 1649의 실제 claim을 확인했다. 이를 첫 자동 게시 완료로 간주하지 않는다. 각 자동 생성 시도의 상태·시간·해시는 기존 DB 추적 경로에 남긴다.

구체적 전후 프레임·동일 프롬프트 이미지·영상 해시는 lattae-feed PR #4의 `docs/editorial-validation-2026-11-25.md`에 기록했다. 공간 배치·장비 디테일과 군복 형태의 세부 정확성에는 한계가 남아 있다. 생성 사진은 실제 인물·현장·2014년의 기록 사진이 아니며, 경영 논의 장면이 실제 법적 조직 구조를 보여주는 것도 아니다. 사람 품질 검수는 대기다. 근거 기반 텍스트 검토가 사람 검수나 완벽한 사실성 보장은 아니다.
